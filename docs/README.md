# BAB — Documentazione MVP

Riorganizzazione completa del materiale della founder, letto riga per riga e
rimesso in ordine logico: dalla visione → al modello → al prodotto → al design →
alle decisioni ancora aperte.

**Come leggere questa cartella.** È ordinata dal "perché" al "come".
Se hai 10 minuti, leggi solo [`00-fondamenta/01-visione-e-problema.md`](00-fondamenta/01-visione-e-problema.md)
e [`02-prodotto/01-architettura-informativa.md`](02-prodotto/01-architettura-informativa.md).
